## Context

The group runs several travel brands for a global audience: train tickets, tours and an internal tool for travel agents. Each product had grown its own UI, and developers often rebuilt the same component for every brand.

## Problem

Design and development were slowed down by inconsistency, not by a lack of ideas. Mockups took long to prepare, handoff needed many clarifications, and the same user pattern behaved differently from site to site.

## What I did

- **Token structure.** Set up colour, type and spacing tokens with themes per brand, so a component changes its look by switching a theme rather than being redrawn.
- **Component library.** Built and documented 2,000+ components and variants in Figma, from inputs and calendars to full booking blocks.
- **Design–code link.** Worked with front-end developers to match the Figma library to Storybook across different tech stacks.
- **Workspace and rules.** Reorganised the Figma workspace and wrote usage guidelines, then reviewed the junior designer’s work against them.
